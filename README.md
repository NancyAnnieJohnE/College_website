**College Website Project**

This is a multi-page responsive website for a college. It showcases:
  -Departments and courses
  -Committees and leadersip
  -Facilities and achievements
  -Placements and career opportunities
  -News & events
  -Contact information with phone numbers and address
The website includes interactive elements like flip cards, hover effects, accordion panels, and a responsive layout for mobile and desktop screens.

**Technologies Used**

  HTML5 – Structuring the website.
  CSS3 – Styling, animations, gradients, flip cards, hover effects, responsive design.
  JavaScript – Flip card functionality and accordion behavior.
  Responsive Design – CSS Grid and Flexbox for mobile-friendly layouts.
